## Сценарій C - Hands-on

Той самий прикордонний роутер, інший день. Клієнти скаржаться на той самий сервіс - сторінка не відкривається.

**Симптом:** цього разу навіть `ping` не відповідає. Виглядає як звичайна проблема зі зв'язністю чи firewall.

Довідка, якщо якісь команди незнайомі:

- `ping` - чи є мережевий звʼязок узагалі
- `curl -I` - HEAD-запит, тільки заголовки, без тіла відповіді
- `curl -v` - повний запит, показує кожен крок
- `ping -M do -s <N>` - ICMP без права на фрагментацію, розміром N байт
- `tcpdump` - які пакети реально йдуть через інтерфейс
- `iptables -L -n -v` - чи щось дропається, і скільки разів

Відтвори проблему:

```
from-client ping -c3 10.10.50.2
from-client curl -I http://10.10.50.2:8080/
```

> Підказки відкриваються поступово в чаті від ведучого

**Ціль:** `curl` з клієнта повертає повну сторінку.

Середовище готується автоматично, десь 10 секунд після старту.
