## Сценарій A — Demo

Сервер має два мережевих інтерфейси: `eth0` (primary) і `eth1` (10.10.20.1/24).
HTTP сервіс запущений на порту 8080. Клієнт розміщений в мережі 10.10.20.0/24.

**Симптом:** клієнт не може підключитись — з'єднання зависає.

---

Підключення від імені клієнта:

```
ip netns exec client curl -v http://10.10.20.1:8080
ip netns exec client ping 10.10.20.1
```

> Середовище налаштовується автоматично (~20 секунд після старту).
