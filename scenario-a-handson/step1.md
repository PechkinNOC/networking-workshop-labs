## Знайди і виправ проблему

Сервіс слухає на `0.0.0.0:8080`. Клієнт не може підключитись.

```bash
# Перевір стан сервісу
ss -tlnp

# Перевір з'єднання від клієнта
ip netns exec client curl -v http://10.10.20.1:8080

# Підказки відкриваються поступово в чаті від фасилітатора
```

**Ціль:** curl від клієнта повертає відповідь від HTTP сервера.
