## Рішення

**Відхилення 1:** Форвардер слухає на `127.53.53.53` — теж loopback, контейнер не бачить.

**Відхилення 2:** docker0 bridge перевизначений на `172.31.0.1` — не можна просто написати `172.17.0.1`.

**Рішення:**

```bash
# Знайти актуальний IP docker0 (не вгадувати!)
ip addr show docker0
# → 172.31.0.1

docker run --dns 172.31.0.1 alpine nslookup google.com
```

**Ключовий висновок:** docker0 IP треба перевіряти, не вгадувати. `127.53.53.53` — теж loopback.
