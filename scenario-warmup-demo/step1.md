## Веди за чатом, не за собою

Не виконуй кроки самостійно - питай чат "що перевіримо?" і виконуй те, що пропонують. Повний список типових підказок і як на них реагувати - у `workshop.md`, розділ 5.

Довідкові команди (для тебе, не для показу заздалегідь):

```bash
curl -v http://api.internal:8080/
ping -c2 api.internal
nslookup api.internal
dig api.internal
ss -tlnp
getent hosts api.internal
cat /etc/hosts
```
