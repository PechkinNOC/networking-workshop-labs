## Сценарій C - Demo

Є сервер, з якого періодично ходять на зовнішній сервіс (`https://example.com`). Моніторинг зелений, помилок немає - просто це довше, ніж мало б бути.

`curl` до того самого адреса - швидкий. А тестовий Python-скрипт, який робить те саме, - повільний, ~2 секунди на запит.

Проблема: чому один інструмент швидкий, а інший ні, якщо обидва йдуть в один і той самий сервіс?

Запусти тестовий скрипт:

```
python3 /opt/testapp.py
```

Порівняй з curl:

```
time curl https://example.com
```

Середовище готується автоматично, десь 10 секунд після старту.
