## Сценарій C — Demo

Моніторинг зелений. Помилок немає. Але є скарга: додаток повільний при зверненні до зовнішніх сервісів.

**Симптом:** `curl https://example.com` — швидко. Python додаток — повільно (~2 секунди на запит).

---

Запуск тестового Python додатку:

```
python3 /opt/testapp.py
```

Порівняння з curl:

```
time curl https://example.com
```

> Середовище налаштовується автоматично (~10 секунд після старту).
